# Практическая работа 19

Простое REST API для управления пользователями на `Express` с подключением к `PostgreSQL` через `Neon`.

## Запуск

```bash
npm install
npm start
```

Сервер запускается на `http://localhost:3000`.

## Маршруты

- `POST /api/users` - создать пользователя
- `GET /api/users` - получить список пользователей
- `GET /api/users/:id` - получить одного пользователя
- `PATCH /api/users/:id` - обновить пользователя
- `DELETE /api/users/:id` - удалить пользователя

## Пример тела запроса

```json
{
  "first_name": "Иван",
  "last_name": "Иванов",
  "age": 20
}
```

При запуске приложение автоматически создает таблицу `users`, если она еще не существует.

## Как посмотреть данные

1. Запусти сервер:

```bash
npm start
```

2. Открой в браузере:

- `http://localhost:3000/`
- `http://localhost:3000/api/users`

3. Чтобы посмотреть базу напрямую в Neon, открой `SQL Editor` и выполни:

```sql
SELECT * FROM users ORDER BY id;
```

## Тестовые данные

Чтобы добавить демонстрационных пользователей, выполни:

```bash
npm run seed
```
