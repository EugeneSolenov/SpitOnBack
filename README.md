# Практики 13-23

В репозитории собраны практические работы по дисциплине "Фронтенд и бэкенд разработка" с постепенным развитием приложений: от PWA для заметок до REST API, кэширования, балансировки нагрузки и контейнеризации через Docker.

## Структура

- `Pr13-14` — проект для практик 13 и 14
- `Pr15-17` — доработанная версия проекта для практик 15, 16 и 17
- `Pr19` — REST API пользователей на `Express` и `PostgreSQL` через Neon
- `pr20` — REST API пользователей на `Express` и `MongoDB Atlas`
- `pr21` — проект с Redis-кэшированием и фронтендом
- `pr22` — балансировка нагрузки через Nginx и HAProxy в Docker Compose
- `pr23` — материалы практики 23; реализация контейнеризации выполнена на базе решения из `pr22`

## Практика 13

- Базовое PWA-приложение для заметок.
- Хранение заметок в `localStorage`.
- Подключение `Service Worker`.
- Кэширование основных файлов и офлайн-страница.

## Практика 14

- Доработка интерфейса приложения заметок.
- Создание, редактирование, удаление и поиск заметок.
- Улучшение клиентской логики и работы без сети.

## Практика 15

- Перевод проекта на App Shell-подход.
- Запуск по `HTTP` и `HTTPS`.
- Подготовка PWA к безопасной работе в браузере.

## Практика 16

- Добавлен `Socket.IO` для обновлений в реальном времени.
- Реализованы push-уведомления через `Service Worker` и `web-push`.
- Добавлены подписка и отписка от уведомлений.

## Практика 17

- Добавлены заметки с напоминанием по дате и времени.
- На сервере реализовано планирование напоминаний через `setTimeout`.
- В push-уведомлении добавлена кнопка `Отложить на 5 минут`.
- `Service Worker` отправляет запрос на сервер для переноса напоминания.

## Практика 19

- Реализовано REST API для управления пользователями на `Express`.
- Подключена база данных `PostgreSQL` через Neon.
- Добавлены CRUD-маршруты `/api/users`.
- Настройки подключения вынесены в `.env`, пример хранится в `.env.example`.
- Добавлен скрипт заполнения тестовыми данными через `npm run seed`.

## Практика 20

- Реализовано REST API для управления пользователями на `Express`.
- Подключена облачная база данных `MongoDB Atlas` через `mongoose`.
- Добавлены CRUD-маршруты `/api/users`.
- Строка подключения хранится в `.env`, пример настроек находится в `.env.example`.
- Добавлен скрипт очистки и заполнения коллекции тестовыми данными.

## Практика 21

- Проект дополнен Redis-кэшированием GET-запросов.
- Кэшируются списки и отдельные записи пользователей и товаров.
- Для пользователей используется TTL 1 минута, для товаров — 10 минут.
- Ответы содержат поле `source`, по которому видно, пришли данные с сервера или из кэша.
- Сохранены backend, frontend, Swagger-документация и smoke-проверка.

## Практика 22

- Реализована тестовая система балансировки нагрузки для backend-сервисов.
- Добавлены три экземпляра backend: два основных и один резервный.
- Настроены Nginx и HAProxy с round-robin, health checks и резервным сервером.
- Для Nginx добавлены параметры отказоустойчивости `max_fails` и `fail_timeout`.
- Добавлены скрипты проверки балансировки и failover-сценария.

## Практика 23

- Изучена контейнеризация приложений с Docker, Dockerfile и Docker Compose.
- Решение практики 22 оформлено как контейнеризированный стек.
- Backend-сервисы собираются из общего `Dockerfile` и запускаются отдельными контейнерами.
- Все сервисы объединены в одну Docker-сеть и обращаются друг к другу по именам контейнеров.
- Nginx работает как балансировщик нагрузки поверх контейнеров `backend1`, `backend2` и `backend3`.
- Проверена балансировка повторными запросами и отказоустойчивость при остановке одного или нескольких backend-контейнеров.

## Запуск

### Практики 13-14

```powershell
cd Pr13-14
npm install
npm start
```

Адрес запуска:

- `http://localhost:3001`

### Практики 15-17

```powershell
cd Pr15-17
npm install
npm start
```

Адреса запуска:

- `http://localhost:3001`
- `https://localhost:3443`

Для проверки push-уведомлений и напоминаний рекомендуется использовать `HTTPS`.

### Практика 19

```powershell
cd Pr19
npm install
npm start
```

Сервер запускается на `http://localhost:3000`.

Для заполнения PostgreSQL тестовыми данными:

```powershell
npm run seed
```

### Практика 20

```powershell
cd pr20
npm install
npm start
```

Сервер запускается на `http://localhost:3000`.

Для заполнения MongoDB тестовыми данными:

```powershell
npm run seed
```

### Практика 21

```powershell
cd pr21
docker run -d --name redis-cache -p 6379:6379 redis
npm install
npm --prefix frontend install
npm run dev
```

Адреса:

- Backend: `http://localhost:3000`
- Frontend: `http://localhost:5173`
- Swagger: `http://localhost:3000/api-docs`

Проверка:

```powershell
npm run smoke
npm --prefix frontend run build
```

### Практики 22-23

```powershell
cd pr22
npm install
npm run compose:up
```

Адреса:

- Nginx: `http://localhost:8080`
- HAProxy: `http://localhost:8081`
- HAProxy Stats: `http://localhost:8404/stats`

Проверка балансировки:

```powershell
npm run test:balance
```

Проверка отказоустойчивости:

```powershell
npm run test:failover
```

Остановка контейнеров:

```powershell
npm run compose:down
```
