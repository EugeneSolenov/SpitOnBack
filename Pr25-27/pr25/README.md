# Практика 25

React-приложение на Vite с двумя маршрутами, lazy loading и анализатором бандла.

## Запуск

```powershell
npm install
npm run dev
```

Адрес разработки:

```text
http://localhost:5174
```

## Сборка

```powershell
npm run build
```

После сборки отчёт анализатора будет в файле `dist/bundle-report.html`.
